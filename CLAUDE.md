# PachaLab

Asset and content staging directory for the PachaLab website (Stephanie Vargas Aguilar), which is
hosted as a **Google Site**. This directory contains no source code: the site's pages and layout live
in Google Drive, not here. Nothing in this tree builds, runs, or deploys.

## What is actually here

- `pachalab/PachaLab.gsite` — a 164-byte JSON Drive shortcut (`doc_id` `[drive-doc-id]`,
  owner `[owner account, recorded privately]`), not site content. Its own first field reads "DO NOT EDIT THIS FILE!
  ANY CHANGES MADE WILL BE LOST!". Opening it launches the Sites editor in a browser; page text,
  structure, and styling cannot be read or recovered from this file.
- `pachalab/figures/` — images uploaded to or staged for the site: portraits (`stefi.jpg`,
  `Foto_SV.jpg`), link icons for email / LinkedIn / CV / Google Scholar, and `heart-icon-01.png`
  (cardiac-regeneration theme). Several filenames contain spaces — quote paths in shell commands.
- `pachalab/files/Vargas_CV_July2025.pdf` — the CV linked from the site.
- `pachalab/stefi.bib` — JabRef BibTeX database (`databaseType:bibtex`), 8 `@Article` entries spanning
  2010–2024. This is the publication list backing the site's publications section.

## Research domain (from the bibliography)

Cathepsin L / autophagolysosome turnover (2010), microglia development and macrophage self-renewal
(Science 2016, EMBO J 2017), Immgen consortium work (Nat Immunol 2020, 2022), and first-author work
from the Olson lab on neonatal heart regeneration and the PD-1/PD-L1 immunosuppressive environment
(Circ Res 2023 abstract, Nat Cardiovasc Res 2024). Citation keys follow `author.etal{year}.{journal-abbrev}`.

## Working conventions

- No build system, package manager, tests, CI, or git repo. There are no commands to run.
- Editing the live site requires Google Sites. Changing `figures/` or `files/` here does **not**
  propagate to the published page; assets must be re-uploaded in the Sites editor.
- `stefi.bib` is JabRef-managed — per global instructions, ask before editing any `.bib` file, and
  keep key style and entry formatting consistent with the existing records.
- Naming differs at every level: working directory `patchalab/`, inner folder `pachalab/`, site
  "PachaLab". Verify all three before renaming any of them.
